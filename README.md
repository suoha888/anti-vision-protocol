## 🧭 为什么需要“反向愿景（Anti-Vision）”？

99% 的新年计划和美好目标之所以注定流产，是因为假大空的宏大叙事根本无法对抗当下的廉价多巴胺。

人类远古大脑对**“逃离极端厌恶、痛苦与耻辱”**的神经反应，远比对“美好愿景”要强悍数倍。

Dan Koe 指出：
- **你必须先残忍、露骨地写下你 5 年后绝对无法忍受的最惨生活画面（The Brutal 5-Year Tuesday）**；
- 测出你的“沉沦危险指数（Decay Risk）”；
- 刺破你潜意识中为了自我保护而设立的虚假借口；
- 倒推建立 **5 大不可逾越的每日防御红线（The Non-Negotiables）**，把负向能量转化为不可动摇的正向执行力。
